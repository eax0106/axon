Response-time budget

Phase 1 passes only if the agent answers fast enough to feel human. To measure it, we split the delay between "caller stops talking" and "caller hears the first word" into parts.

Treply ≈ tturn + tstt + tllm + ttts + tnet  <  1000 ms

Each part, in plain words (milliseconds)

  • tturn: time to decide the caller has finished (VAD + Smart Turn)
  • tstt: time to get the final transcript after they stop
  • tllm: time until the LLM finishes its first sentence
  • ttts: time until the voice service returns the first audio chunk
  • tnet: network and phone-line overhead in both directions

Key findings

Risks and open questions

High

Which phone numbers are legal for lead calls

TRAI (Feb 2025) says promotional calls must come from 140-series numbers, not ordinary 10-digit ones. Outpero uses 10-digit numbers. Whether calling a lead who just enquired counts as "promotional" needs a lawyer's view before launch [S10, S11].

Medium

Vobiz connector and docs

No official Vobiz API reference was found; we rely on Sarvam's guide and community docs. Rates and the KYC sub-account API are also not found. Ask Vobiz directly [S3, S4].

Medium

Call quality on phone lines

Telugu and Hindi transcription and voice quality on 8 kHz phone audio is untested for every provider.

Medium

Data protection (DPDP)

Core duties start 13 May 2027: clear consent notices, security, breach reporting, user rights. We build consent records and data deletion in from the start [S12].

Open

Cost per minute

LLM and phone costs are not measured yet, so the margin on each tier is unknown.

Rule

Copy features, not material

Match what Outpero does. Don't copy its code, prompts, help-centre text or brand.
