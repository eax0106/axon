# F11 — Developers, settings, support

Branch `phase/f11-developers`.

## What was built

- **Developers** (`/developers`): API status for the last 24 hours (version, requests, server errors, webhooks sent and failed) and the OpenAPI and Postman downloads, then four tabs:
  - **Keys**: name and create a key (up to 20 active); the full key is shown once with a copy button and the warning that it can't be seen again. Each key shows its prefix, when it was made and last used; revoke is confirmed and takes effect at once.
  - **Webhooks**: https address, optional description, and the events picked from the API's own list (with each one's description). The signing secret is shown once. Each webhook can be paused or resumed, sent a test event (the answer is shown), have its secret rotated (confirmed; the new secret is shown once) or be deleted (confirmed).
  - **Deliveries**: every webhook send with its event, HTTP answer or error, attempt count and status, filterable by status, with a resend.
  - **Requests**: every request made with an API key, with method, path, status and time; "errors only" filter.
- **Account** (`/account`) gains:
  - **Business**: account name, the business name employees say on calls, and the longest call (minutes; every call hangs up there). Members see it read-only. The accepted terms version is shown (there is no terms text to accept yet).
  - **Password**: a wrong current password is refused next to the field; a right one gives this tab a fresh session (other sessions are signed out by the API).
  - **Do not call**: paste one or many numbers (one per line or comma-separated) with an optional reason; the answer says how many were added, already listed and not phone numbers. Search by digits; the owner can remove a number (confirmed).
- **Support** (`/support`): a chat with the Axon team (staff replies show as "Axon team", refreshes every 30 s, ⌘/Ctrl+Enter sends) and a product feedback box.
- **Call detail**: rate a finished call 1–5 with an optional note; it goes to the Axon team.
- Rail and ⌘K gain Developers and Support; Account is also found by "password", "do not call", "terms".

Team invites are not built: the backend has no API for them (owner decision 2026-10-30).

## How to run

As F1. `e2e/developers.spec.ts`: a key shown once works on `/v1/account`, appears in the request log, and is refused after revoking; a webhook with two events shows its secret once, rotates it to a different one and pauses; settings save (checked through the API); a wrong current password is refused, a right one keeps the session across a reload while the old password stops working; do-not-call bulk counts, a repeat add counted as already listed, search, confirmed removal; a finished call rated 2 from its page (checked in the database); a support message shows in the thread and feedback is thanked; axe clean at desktop and 375 px. All 12 e2e tests pass.
