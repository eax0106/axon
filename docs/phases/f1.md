# F1 — Foundation, contracts, app shell

Branch `phase/f1-foundation`. Track 2 plan in docs/PLAN.md, approved by the owner on 2026-10-30.

## What was built

- **packages/contracts.** `openapi.json` exported from the FastAPI app by `scripts/export_openapi.py`, and `src/schema.d.ts` generated from it with openapi-typescript. CI fails if either is stale.
- **apps/web.** Vite + React 19 + TypeScript (strict, `noUncheckedIndexedAccess`), Tailwind 4.
  - Every colour is a CSS variable in `src/styles.css` (DESIGN_DIRECTION §2, dark and light). Tailwind's own palette is switched off, so only token utilities exist. A test fails the build on any hex or rgb colour in a component.
  - Fonts self-hosted: Manrope (display), Inter (UI), Noto Sans Telugu and Devanagari as fallbacks. Each script's subset loads only when the page uses it.
  - Motion tokens (durations, easings) live in `styles.css` `@theme`; a JS `motion.ts` comes with the first JS-driven animation (F3).
  - API client: openapi-fetch typed from the contracts, bearer token, a 401 signs out cleanly and returns to the page after sign-in, `ApiError` exposes the `provider_not_configured` body.
  - Shell: left rail (drawer under 768 px), top bar with credit chip (warns when low), live-call indicator, notifications bell (optimistic mark read and mark all read), ⌘K / Ctrl K command palette (pages, theme, sign out), light and dark themes with no flash on load, skip link, mint focus ring, 300 ms enter-only page cross-fade, calm reduced-motion fallback.
  - States: skeletons; `ErrorState` shows a missing vendor key as "Connect <vendor> to use this" with the key names, anything else as an alert with retry.
  - Pages: a plain sign-in (F2 adds sign-up, terms, phone check) and an Overview of the account and wallet.
- **Compose.** `web` service: the app built on Node 20, served by nginx, which proxies `/api` (HTTP and WebSocket) to the API. One origin, so the API needs no CORS.
- **CI.** `web` job on macOS, Windows and Linux (install, typecheck, test, build, first-load budget); `contracts` freshness job; the compose job now runs the Playwright end-to-end test with axe against the served app.
- **Backend.** `POST /public/otp/{token}` and its GET twin shared one OpenAPI operation id; each now has its own, so the client generates cleanly.

## Decisions and notes

- Light-theme accent is `#107c44`, not the proposed `#138a4b`, which is only 4.0:1 on `--bg-deep`. Light status and chart colours are darker versions of the dark ones for the same reason. All pairs are checked in `src/lib/contrast.test.ts` (text 4.5:1, chart marks 3:1).
- Older majors on purpose: react-router 7, vitest 4, jsdom 27, TypeScript 5.9; the newest of each need Node 22. pnpm is pinned to 10.x.
- Most API responses are declared as plain objects in the schema, so the web app names the shape it reads at each call (`unwrap<T>`). Adding response models to the API would make those types generated too.
- The live-call indicator counts ringing and in-progress calls among the newest 100 (there is no live-count endpoint). It can only undercount if over 100 newer calls are queued behind a live one.
- Behind nginx every request reaches the API from the proxy's address, so the per-address sign-in limits count all users together unless uvicorn trusts the proxy (`FORWARDED_ALLOW_IPS`). Set that for the real proxy at hosting time (Track 3).

## How to run

```
pnpm install                                        # Node 20, corepack enables the pinned pnpm
docker compose -f deploy/docker-compose.yml up -d postgres redis api
pnpm --filter web dev                               # http://localhost:5173, proxies /api to :8000
pnpm typecheck && pnpm test && pnpm build
pnpm --filter web size                              # first-load budget, 150 KB gzip
docker compose -f deploy/docker-compose.yml up -d --build --wait   # app at http://localhost:8080
pnpm --filter web exec playwright install chromium && pnpm --filter web e2e
uv run python scripts/export_openapi.py && pnpm --filter @axon/contracts gen   # after an API change
```
