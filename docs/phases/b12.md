| Events | `events.py`, `hooks.py`, `settle.py` | Six events: `call.completed`, `call.not_connected`, `call.inbound_answered`, `call.inbound_missed`, `lead.created`, `campaign.status_changed` (with `previous_status`). ## Decisions

See `docs/DECISIONS.md` (six rows dated 2026-10-27 for B12). The ones worth a second look:

- **Outbox plus scan, not calls in the engine.** Events are rows written with the change. That covers every path that creates a lead or moves a campaign, and calls are found by what the database says has ended, so the engine and the carrier callbacks did not change.
- **Voicemail comes from the analysis, not the carrier.** The codebase has no answering-machine detection. A call is voicemail only with a quote from the recording in the transcript, so a person is never mislabelled without evidence.
- **The OpenAPI check is ours.** `openapi-spec-validator` is not in `BUILD_PLAN §2`, so the tests check structure (operation ids, `$ref`s, security on every operation, no internal paths) with a negative control for each rule. The owner can approve the library if a full validator is wanted.
- **Old calls are not announced.** The migration marks every call that had ended as announced.

## Open items

- **n8n, Make and Zapier guides** (PARITY) are help-centre content for Track 2. The API, spec and webhooks they use are done; "n8n receives events" is a wiring check.
- **The key limit fails open** when Redis is down, and the allowance is per key, not per account.
- **Members can see the key list (name and first characters only) and the request log.** Only owners create or revoke keys and webhooks. Say if members should not see them.
- **Webhook response body is not shown** in the delivery log (only the status code and a short error), because reading it from an owner-chosen address was judged riskier than useful.
- **No event versioning yet.** The REST API is `/v1`; the webhook envelope has no version field, so a breaking change to an event needs one added first.
- **Result webhook secret rotation** is a PUT with a new secret; there is no separate rotate button for it.
- **A call whose analysis never finishes** is announced after 20 minutes without an outcome.

## How to run

```bash
docker compose -f deploy/docker-compose.yml up -d postgres redis
uv run alembic -c services/api/alembic.ini upgrade head && uv run python -m app.voices
AXON_TEST_DATABASE_URL=postgresql+asyncpg://axon:axon@localhost:5432/postgres AXON_TEST_REDIS_URL=redis://localhost:6379/5 uv run pytest
```

Make a key with `POST /developer/keys`, then `curl -H "Authorization: Bearer axk_live_…" $API/v1/account`. Create a webhook with `POST /developer/webhooks`; the worker (`python -m arq worker.main.WorkerSettings`) sends the events. No new environment variables or keys.
