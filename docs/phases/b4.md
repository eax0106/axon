# B4 — AI employee builder

Branch `phase/b4-employee-builder`. Builder: axon-builder-sonnet, with the `ponytail` and `unlazy` skills loaded at the start of the phase. Gate ledger: `.unlazy/axon/gates/b4.md` (untracked, in the builder worktree).

## What was built

| Area | Where | Notes |
|---|---|---|
| Script bundle and settings | `services/api/app/employees/script.py` | `ScriptBundle` (welcome, agent information, sections, end rules, FAQ, strictness 1–5, pre-call variables) is the publish-gated content. `EmployeeSettings` (TTS speed, ambience + volume, style pack, power prompting, AI acknowledgement, capture fields) applies to live calls at once. |
| Prompt compiler | `employees/compiler.py` | `compile_prompt(...)` → one system prompt. Script = content (call flow, FAQ), rules = conduct (end rules, honesty, brevity; they override the flow), voice = delivery only: speed and ambience never reach the prompt (tested). Strictness picks one of five adherence clauses. `{{name}}` pre-call variables fill from the lead; a declared but missing value becomes "(not provided)", an undeclared placeholder stays visible. The FAQ heading is always emitted. Prompts are our own text. |
| Lifecycle | `employees/lifecycle.py` | `draft → training → live ⇄ paused`. First publish moves draft to training; `activate` (owner) needs a published version and an attached number; `deactivate` pauses a live employee. |
| Versions | `employees/service.py` | `publish` stores the draft as the next version and keeps exactly the last 3. `restore(n)` re-publishes an old version as a new version (history stays linear and capped). `revert` discards pending edits. `has_pending_edits` compares the draft to the newest version. |
| Employee API | `employees/router.py` | `POST/GET/PATCH/DELETE /employees`, `/duplicate`, `PUT /script`, `PUT /settings`, `GET /prompt?source=draft\|live`, `/publish`, `/revert`, `/versions`, `/versions/{n}/restore`, `/activate`, `/deactivate`, `/switch-mode`, `/reset`. Everything is scoped to the caller's account (another account's id is a 404). Owner-only: delete, activate, deactivate, switch-mode, reset. Defaults: purpose by channel (instant and inbound service, bulk promotional), a Value-tier voice for the language, an auto avatar (initials + hue). |
| AI builder | `employees/ai.py` | `POST /ai/brief-questions`, `/ai/draft-agent`, `/ai/structure-prompt`, `/employees/{id}/ai/edit-flow` (a proposal, nothing saved), `/ai/transcribe-chunk` (body is the WAV; the client joins the text of its chunks), `/employees/{id}/chat` (text sandbox on the compiled prompt). They use the selected LLM and STT adapters, so without keys they answer 503. Model output is parsed defensively; a bad shape is `502 ai_output_invalid`. A vendor failure is `502 provider_error`. |
| Vendor calls | `providers/speech/*.py`, `providers/telephony/vobiz.py` | Adapters now also `complete` (Gemini, Sarvam), `transcribe` (Sarvam, Smallest), `synthesize` (Sarvam, Smallest, Cartesia) and Vobiz `originate`, written from the vendors' own REST docs (see open items). |
| Voices | `app/voices.py`, `compose` | Catalog in code (`SEED`), seeded by `python -m app.voices` (Compose runs it after migrating; idempotent). `GET /voices?language=&tier=` is the picker; `POST /voices/{id}/preview` speaks a sample through the voice's own vendor. `language_scores` holds a conservative 0.7 for each documented language and is a placeholder until native-speaker QA. Cartesia has English voices only until Hindi and Telugu ones are chosen with the key. |
| Test calls | `employees/calls.py` | `POST /employees/{id}/test-call {phone}` rings an Indian mobile from the employee's number on its **draft** script; `POST /employees/{id}/web-test-call` returns a 2-minute signed ticket and a `wss://` URL for the browser. Both create a free `calls` row with `is_test = true`, capped at 5 an hour per employee. |
| Engine | `services/engine/engine/` | Answer URL and stream take `employee=` (and `call=`). `plan.py` loads the newest published version, or the draft only when `call` is a test-call row of that employee. The TTS is built from the employee's voice row (vendor, voice id) and speed — `engine/services.py` factories take a `Delivery(voice_id, speed)`; the env/constant voices remain only as a fallback for calls with no employee. `web.py` is the browser protocol and `/web/stream?ticket=` the endpoint. |
| End-of-call hang-up | `engine/goodbye.py`, `call.py` | The LLM gets an `end_call` function. `GoodbyeGate` waits until the bot has stopped speaking and Vobiz has confirmed (`playedStream`) every utterance checkpoint, then ends the call; a 15 s timeout hangs up anyway. (B2 carry-over.) |
| Ambience | `engine/ambience.py` | `SoundfileMixer` under the bot's audio when `AXON_AMBIENCE_DIR/<name>.wav` exists. No sound files are shipped (see open items). |
| Schema | `migrations/0002_employee_builder.py` | `employees.settings` (JSONB) and `calls.is_test`. |

## Decisions

- **Draft vs live.** `employees.draft` is the editable bundle; calls use the newest `employee_versions` row. Settings (voice speed, ambience, toggles, capture fields) are instant by the parity rule and live in `employees.settings`.
- **Restore creates a new version** with the old content rather than rewinding, so retention stays exactly three and "restore any of the last 3" works repeatedly.
- **First publish moves draft to training.** The parity lifecycle names the four states but not the moves; this is the smallest rule that needs no extra button.
- **Power prompting** (our reading): the owner's agent information is emitted verbatim instead of inside our framing. **Style pack**: a warmer conversational-style clause. **AI acknowledgement**: say early that it is an AI; off, it still tells the truth if sincerely asked.
- **Purpose default by channel** (instant and inbound = service, bulk = promotional) until the B7 rule table and legal opinion settle it.
- **Voice rows decide the TTS vendor** at call time (`voice.provider`), so a Premium voice with no Cartesia key is a `503 provider_not_configured` naming the key, never a silent switch. Fallback from Premium to Value is B13.
- **Test calls are limited** to Indian mobile numbers and 5 per employee per hour because they are free and the endpoint is reachable by any account member.
- **No `python-multipart`:** the voice-brief endpoint takes the WAV as the request body, which avoids an extra dependency. New dependencies: none.

## Open items for wiring (Track 3) and later phases

- Real-use contract tests (`test_ai_contract.py`: LLM JSON mode, voice previews, transcription, call placement; plus B3's synth/transcribe/complete tests) confirm these unconfirmed vendor facts once keys exist: Sarvam `text-lid` health body; Gemini `generateContent` field names (`systemInstruction`, `responseMimeType`, `thinkingConfig`) and whether `gemini-2.5-flash` is open to the key; Smallest Pulse accepts `te` (we send `multi-indic` for Telugu until proven); Smallest TTS path `/waves/v1/tts` with `Accept: audio/wav`; Cartesia `/tts/bytes` and its Hindi/Telugu voices; Vobiz `originate` field names and that `from` must be a number on the account.
- Ambience sound files are not in the repository (none we may ship exist yet); the setting is stored and mixed when a file is present. Owner decision: commission or license five loops.
- Captured fields are declared and the prompt asks for them; extracting their values from the call is B6 (post-call) and B10 (in-call actions). Pre-call variable values arrive with leads in B5 and B8.
- Calls do not yet update their own `calls` rows (status, duration): that is the dialer (B5) and post-call (B6).
- B4 voice picker reads the `voices` table (done); the B3 constants stay only as the no-employee fallback.
- B13: a Premium employee whose Hindi or Telugu Cartesia voice is missing is the "Premium falls back to Value at the Value price" case; failover must treat a build-time `ProviderNotConfiguredError` as unhealthy.

## How to run

```bash
docker compose -f deploy/docker-compose.yml up -d postgres redis
uv run alembic -c services/api/alembic.ini upgrade head && uv run python -m app.voices
AXON_TEST_DATABASE_URL=postgresql+asyncpg://axon:axon@localhost:5432/postgres AXON_TEST_REDIS_URL=redis://localhost:6379/5 uv run pytest
```

With keys in `.env`, `uv run --env-file .env pytest services/api/tests/test_ai_contract.py services/engine/engine_tests/test_speech_contract.py` runs the real-vendor tests (`AXON_TEST_FROM` and `AXON_TEST_PHONE` enable the call placement test).
