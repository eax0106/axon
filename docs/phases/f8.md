# F8 — Bulk campaigns

Branch `phase/f8-bulk`.

## What was built

- **Campaigns** (`/campaigns`): every campaign with its status and a progress bar of finished contacts; create one for any Bulk employee (or a pointer to hire one).
- **Campaign page** (`/campaigns/:id`), four tabs:
  - **Live**: the **constellation**, one dot per contact (mint when reached, sage when nobody answered, info blue for call-backs, faint when skipped or cancelled, breathing while on a call), with a "finished / total" counter and a legend of counts; calling now (with Listen in) and the call-backs callers asked for. Refreshes every 4 s while running.
  - **Contacts**: import a CSV file or pasted rows. "Check the columns" shows the first rows; only an exact column name is pre-selected (phone, name, a script detail), everything else the owner picks, so nothing is guessed. The import reports the API's own counts (added, already there, do-not-call, excluded, repeated in the file, invalid, details left empty) and can save the list for reuse. Add one by hand, add a saved list, keep numbers out of this campaign (exclusions), and per-contact Call now, Cancel and Retry.
  - **Settings**: calling window (9 AM–9 PM IST at most), days, holiday dates, calls at once (1–20), skip the do-not-call list (a person who asked not to be called is always skipped), retries and the gap between them, same run or next day, repeat daily or weekly, and the cross-campaign repeat window. Editable while draft, scheduled or paused.
  - **Analytics**: calls placed, answer rate, people reached, credits spent, by-day bars, outcomes.
- **Actions** shown only when they apply: Start (or Confirm and resume after new contacts), Pause, Resume, Cancel (confirmed), Export CSV, Retry unanswered, Cancel call-backs, Restore not called.
- **Start**: the capacity estimate (contacts, calls at once given the number's lines, working days, cost if everyone answers against the balance, older campaigns ahead on the same number), the consent statement with a tick box, and start now or at a chosen time.

## API change

`GET /campaigns/:id` now also returns `consent_statement`, the exact words the owner ticks. They were stored word for word but not available before confirming, so the screen could not show them without copying the text. A test checks the statement shown is the one stored.

## Measured

2,000 contacts in the constellation (a running campaign seeded by import and SQL): 179 frames sampled, 16.7 ms average, none over 34 ms. Only the calling dots animate (opacity).

## How to run

As F1. `e2e/campaigns.spec.ts`: create; import with a Telugu name through the mapping preview (added 2, repeated 1, invalid 1); add by hand; exclude; one dot per contact; settings saved and read back from the API; start refused by the API without consent, the dialog shows the statement word for word and needs the tick, consent stored with that exact text; export downloads; axe clean at desktop and 375 px.
