## Decisions

See `docs/DECISIONS.md` (rows dated 2026-10-28 for B13). The ones worth a second look:

- **Our own failover rule on top of Pipecat's.** Pipecat reports a refused websocket (bad key) as transient, so its failover strategy would never move. `WriteOffFailover` leaves a vendor at its first real error while a backup exists, which is what a caller on the line needs.
- **Premium is never a fallback,** and a call that fell back is billed at the cheapest tier it used, for the whole call.
- **Health is scored from what calls and dials saw,** not from probing vendors, and a failing vendor is tried last rather than removed, so a call can still use it when nothing else is left.
- **Rates and balances are typed in by staff.** None of the vendors has a balance or usage API we could rely on; costs are never guessed where a rate is missing.
- **Inbound callers missed because the platform is down are called back,** like a busy line, because outages are short.

## Open items

- **The Hindi and Telugu apology** (`engine/call.py`, `APOLOGY`) waits for the native-speaker check (WIRING_CHECKLIST).
- **Vendor rates and balances** must be entered by staff before costs, margin and balance alerts mean anything (WIRING_CHECKLIST).
- **The capacity default (100 calls at once)** is a first guess; set `AXON_MAX_CONCURRENT_CALLS` from the host's measured limit (B14 load test).
- **Revenue counts free credits once they are used** (signup bonus, adjustments), because the ledger cannot tell a free credit from a paid one after it is spent.
- **Members can add numbers to the do-not-call list.** Only owners remove them. Say if members should not add.
- **A support session acts as the account's first owner** and shows everything the owner sees; there is no read-only mode.
- **A voice whose own vendor is down still starts the call** when a fallback voice is healthy (the fallback serves the call and it is billed at the cheaper tier).
- **The 10 s LLM timeout** is per request start or idle gap; a very long answer that keeps streaming is not cut.

## How to run

```bash
docker compose -f deploy/docker-compose.yml up -d postgres redis
uv run alembic -c services/api/alembic.ini upgrade head && uv run python -m app.voices
AXON_TEST_DATABASE_URL=postgresql+asyncpg://axon:axon@localhost:5432/postgres AXON_TEST_REDIS_URL=redis://localhost:6379/5 uv run pytest
```

Make a user a platform admin by hand (`UPDATE users SET is_platform_admin = true WHERE email = …`); the admin console is under `/admin`. New optional setting: `AXON_MAX_CONCURRENT_CALLS` (default 100). No new keys or dependencies.
