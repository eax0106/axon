# F12 — Staff admin console

Branch `phase/f12-admin`.

## What was built

- **Backend**: `/accounts/me` now says `user.staff` (platform staff) and `user.support_session` (staff acting as this user), so the app can show the console and the banner. Tested in `test_admin_accounts.py`.
- **Staff console** (`/admin`, its own lazy chunk). The route renders it only for staff outside a support session; anyone else is sent home and never requests the chunk. The rail shows "Staff console" to staff only. Every write says what it changed.
  - **Accounts**: search by name, business or a person's email, paged by 50; detail with credits, employees, numbers, 30-day calls, people and the latest 20 ledger entries. **Adjust credits** (a negative amount takes back; says the new balance). **Support session**: a reason of at least 5 characters starts 30 minutes as the owner.
  - **Support session**: a banner on every page ("Acting as … Every change is logged under your name.") with "End support session", which hands back the staff session and returns to the account. The staff session is kept aside in storage and also comes back when the support session expires (a 401). Any session change clears cached data.
  - **Support inbox**: every account's chat, feedback and call ratings (stars), filtered by kind, with an inline reply that lands in the account's chat and bell.
  - **System**: alerts (vendor failing, balance low, purchases to settle, quiet worker) or "All clear"; database, Redis, worker heartbeat and queue counts (refreshed every 30 s); revenue per day for 7/30/90 days with totals (top-ups, used, vendor cost, margin); an announcement to every account's bell.
  - **Providers**: each vendor's configuration (in use, missing keys, errors) with its live ok/failed score; usage and cost for 1–90 days with unpriced lines called out; rates (set or change, showing old → new); vendor balances (record a reading and an alert level; estimate after spend, low ones in red).
  - **Voices**: the catalogue; add a voice (vendor sets the tier, language scores 0–1); remove with confirmation (the API refuses a voice in use).
  - **Dialing rules**: the full purpose × number series × context table; a click allows or refuses a pairing, a refused one takes a reason; the Instant policy (strict or relaxed); carrier capacity (calls now / limit, numbers, lines) and number purchases to settle (kept or refunded, with a note).

Skipped: editing a voice (the catalogue API doesn't return the language scores, so an edit would overwrite them blind; remove and re-add for now). The inbox shows the latest 100 messages without paging.

## How to run

As F1. Make a staff user with `UPDATE users SET is_platform_admin = true WHERE email = '…'`. `e2e/admin.spec.ts`: a non-staff user is sent home from `/admin`, has no staff link and never requests the `Admin-*` chunk; staff find an account, post 100 credits ("Balance now 150"), start a support session whose banner follows to `/billing` and ends back on the account, reply to a chat message the owner then reads through the API, flip a dialing rule and see it reported; axe clean at desktop and 375 px. All 14 e2e tests pass.
