# F7 — Instant

Branch `phase/f7-instant`.

## What was built

An **Instant** tab on Instant employees (`/employees/:id/instant`):

- **Queue lanes**: Waiting (a ring that empties toward dial time, minutes or seconds left; "Held" for leads waiting on the owner), Dialing, On a call (pulsing, with "Listen in"), Done (with Redial). Refreshed every 5 s; cancel and redial go through the API, which still applies the calling window and the do-not-call list.
- **Lead sources**:
  - Website, forms and automation tools: the lead URL, the secret header with Reveal and Rotate (rotating confirms that the old secret stops working), and a ready-to-copy request example.
  - **Try a lead**: a test lead runs every intake rule without placing a call and shows the result (accepted, repeat, rejected and why, when it would dial); "Call this number now" places a real one-off call.
  - **Meta Lead Ads**: lead form id and page access token (the token is never shown back).
  - **Google Sheets**: connect through Google's consent screen (the return to this tab finishes the connection once and tidies the address), then choose the sheet and range; existing rows are not called.
- **Calling rules**: wait before calling, the calling window as clock times (always inside 6 AM–10 PM, IST), days, what happens to a lead outside the window, the retry ladder (up to 9 retries, each shown in plain words, e.g. "10 min, then 1 h, then 3 h"), and the repeat-lead window. The API's refusals (for example an end before the start) show in place.
- **Leads received**: the intake log with source, reason and outcome, filterable, refreshed every 10 s.

## Notes

- The lead URL shown is this app's origin plus `/api`, which reaches the API through the same proxy as the dashboard. When the app is hosted on its own domain, that is the public URL to give to forms and tools.
- Google's consent screen sends the owner back to `/employees/:id/instant`; that address must be registered in the Google Cloud OAuth client at wiring time (Track 3).
- Found while testing: the calling-rules form remounted whenever the tab refetched after a save, dropping the "Saved" note (and would have dropped edits). It is now seeded once per employee.

## How to run

As F1. `e2e/instant.spec.ts`: test lead accepted and logged; secret reveal and rotate; a lead posted to the public URL with the new secret is logged with the API's reason; calling rules refused then saved (window 10:00–20:00, 3 retries, checked through the API); a queued call shown waiting with its countdown, cancelled to Done; axe clean at desktop and 375 px.
