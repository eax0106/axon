# F9 — Inbound

Branch `phase/f9-inbound`.

## What was built

- **Incoming calls** tab on every employee (`/employees/:id/incoming`):
  - **Inbound employees**: answer day and night, or opening hours as weekly windows in Indian time; hours past midnight (10 PM–2 AM) are saved as two windows, as the API requires (`toWindows`, unit-tested). Outside the hours: take a message (with the closed message) or don't answer. The **recording notice** can be reworded but not removed; empty means the standard notice in the caller's language (shown as the field's placeholder). Greetings for new callers (`{{business_name}}` only, since a new caller's name isn't known) and returning callers (`{{name}}`, `{{business_name}}`); the API's placeholder refusals show in place. Transfer number and when. Auto call-back of missed callers and the morning summary email. "Reconnect the number" re-points the carrier at Axon.
  - **Instant and Bulk employees**: one switch, answer their own leads when they call back.
- **Inbox** (`/inbox`):
  - **Answering now**: when an incoming call is on, it shows live with the orb, stepper and streaming transcript (the F4 view).
  - **Messages and call-backs**: to do / done; the tick is instant (the row leaves at once and comes back if the API refuses) and reversible; the requested call-back time, the employee and a link to the call.
  - **Missed callers**: the plain reason the API gives, and what happened to the automatic call-back (booked, calling, answered, no answer, cancelled, or why none was made).

## How to run

As F1. `e2e/inbound.spec.ts`: hours including an overnight window saved as two; a forbidden placeholder refused in place; greeting, transfer and an empty notice saved and read back from the API; an Instant employee shows only the call-back switch; a message ticked done and reopened; a missed caller's reason; axe clean at desktop and 375 px. All 9 e2e specs pass.
